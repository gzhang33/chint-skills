# 业务规则与统计口径参考 (Business Rules SSOT)

本文档定义了低压配电（框架断路器、塑壳断路器、电能质量、双电源、虚拟工厂等）及各业务部门的数据分析统计口径与字段硬隔离规范。

---

## 1. 核心分析视角与字段隔离

| 分析视角 | 强制硬隔离字段 | 业务含义与场景 | 常见错误防范 |
| :--- | :--- | :--- | :--- |
| **行业维度** | **`终端客户` (terminal_customer)** | 代表新能源、风电、光伏、电力设备、数据中心等实际落地行业企业。 | 严禁下钻代理商/经销商。 |
| **渠道维度** | **`客户名称` (customer_name)** | 代表代理商、经销商、分销网点等渠道流通客户。 | 严禁与终端行业客户混淆。 |
| **实物数量** | **`属性 = '本体'`** | 发票数量默认严格限制本体，剔除附件/零部件对台数统计的虚高干扰。 | 若需包含附件，需显式声明 `-p all`。 |
| **台数替换率** | **$\frac{\text{新产品台数}}{\text{新产品台数} + \text{老产品台数}} \times 100\%$** | 度量实物台数渗透率，**严禁隐式预设计算**，必须由用户或场景明确指定配对（如 `-r "NXA:NA1"`）。 | 替换率度量的是台数占比而非金额占比。 |

---

## 2. 部门与品类范围覆盖

引擎设计原生支持低压配电团队核心品类，并向前/横向兼容其他业务部门：

- **低压配电核心品类**：
  - **框架断路器 (ACB)**：如 NXA、NA1 系列及通用万能式。
  - **塑壳断路器 (MCCB)**：如 NXM、NM1、NXMLE、NM8N 等系列。
  - **电能质量 (Power Quality)**：滤波、补偿、电能治理类产品。
  - **双电源转换开关 (ATS)**：如 NXZ、NZ7 等系列。
  - **虚拟工厂 (Virtual Factory)**：OEM/代工/合作制造类业务。
- **其他兼容业务部门/品类**：
  - **微型断路器 (MCB)**：如 NXB、DZ47 等终端配电产品。
  - **海外/国际业务 (intl)**：诺雅克海外及正泰国际出口产品线。
  - **全量/跨部门 (all)**：跨部门或综合大盘汇总分析。

## 3. 常见指标计算公式

- **销售额 (万元)**：`SUM(sales_income) / 10000`（不含税净收入）
- **发票台数 (台/万台)**：`SUM(invoice_qty)`（默认过滤 `属性='本体'`）
- **销售额同比 YoY (%)**：$\frac{\text{今年销售额} - \text{去年同期销售额}}{\text{去年同期销售额}} \times 100\%$
- **台数同比 YoY (%)**：$\frac{\text{今年发票台数} - \text{去年同期发票台数}}{\text{去年同期发票台数}} \times 100\%$
- **综合毛利率 (%)**：$\frac{\text{销售额} - \text{销售成本}}{\text{销售额}} \times 100\%$
