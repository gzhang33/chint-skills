# 一页纸立项看板分区规格（Zone Spec · RAT 表格模版实测版 · PM 范围）

> chint-pm-RAT 走**模板填充路线**：`template/one_pager_base.pptx`（RAT 表格模版原样 + 附录A/B）是版式唯一正道，
> `scripts/fill_one_pager.py` 只做单元格文字替换与行/列手术，样式构造性继承。
> 基座再生成：`python3 scripts/build_base.py "<RAT 表格模版.pptx>" template/one_pager_base.pptx`。

## 版式总览（13.333 × 7.5 in，单页正文 + 附录A/B）

正文 = **主 12 行 × 9 列大表**（0.09,1.04，13.12×6.35）+ 团队表（3×8，6.42,0.25）+ 标题占位符。

```
主表行结构（r0-r11）：
r0-r1 │ 需求来源(2×2) │ 规划方向 │ 产品平台 │ 项目计划 │ P1-P4 名称/时间
r2-r3 │ L1 需求背景(2×3)      │ 产品定义标题(1×2) │ 技术可行性-可行(1×4)＋正文
r3-r5 │                       │ 外观/材质/认证/性能(3×2) │ 生产可行性-可行(1×4)＋正文
r4-r5 │ 应用场景及客户痛点(1×3)＋正文 │
r6    │ 竞争对手│ 价格、目标成本及毛利(1×4) │ 财务可行性(1×4)
r7-r11│ 值      │ M2策略(5×4)＋浮动规格表   │ 财务摘要(5×4)＋浮动投入/预测表
r8-r11│ 目标行业/值、销售通路/值（左列）
```

## PM 范围 vs 非 PM 区

| 区 | 处置 |
|---|---|
| 标签牌/项目计划/L1/产品定义(含性能)/痛点/竞对/行业/通路/团队/标题 | **PM 填充** |
| 技术可行性、生产可行性、价格成本毛利、财务可行性 | **保留标题条，正文留白**（其他部门续填） |
| 浮动小表（M2 7×7、投入 4×14、预测 4×5） | **已整体删除**（build_base 克隆附录表原型后移除；其他部门续填手段脱离本模板） |

## 样式常量（基座继承，勿手写）

| 元素 | 值 |
|---|---|
| 灰底（标题条/标签牌单元格） | `bg1 + lumMod 85%`（D9D9D9） |
| 正文字体 | CHINTinno 9-10pt（模板原生混微软雅黑，允许继承；校验器按基座白名单拦新增字体） |
| 标题 | 20pt #237AE4 PLACEHOLDER（layout12，logo 同源） |
| 项目符号 | 正文 Ø；策略/性能 ➢（Wingdings "p"）；财务 • |
| 加粗语义 | 内联"xx：值"段落一律**标签加粗、值 regular**（外观/材质/认证/应用场景/客户痛点，fill 显式置 b 位） |
| 表格边框 | 逐单元格 accent1 lumMod75 0.5pt |
| verdict 区 | 非 PM，模板原文黑字保留 |

⚠️ 基座表格为 **WPS 式合并模型**（gridSpan 原格 + hMerge 续格 / rowSpan + vMerge 续格，
每行物理 tc 数 = 列数）。`tplkit.delete_col` 已兼容；填充一律走 python-pptx `table.cell(r,c)` 寻址。

## 单元格字符预算（fill_one_pager 内建强制；主表行会膨胀推挤版面，超限拒生成）

宽度全角 1 半角 0.5。行宽基准：L1 32 字/行（9pt）、L2/M1 26-27 字/行（10pt）。

| 分区 | 预算 | 判定 |
|---|---|---|
| 标题 | 30 | 硬 |
| 标签牌 | 需求来源 12 / 规划方向 14 / 产品平台 17 | 硬 |
| 承接单位 | 30 | 硬 |
| L1 | intro ≤96（3行）；条目各 ≤64（2行）；合计 ≤10 行 | 硬 |
| L2 | 场景+标签+Σ痛点 ≤ **6 行**（26 字/行）；单条 ≤2 行 | 硬 |
| L3 三值 | 各 20 | 硬 |
| M1 | 外观/材质/认证各 ≤54（2行）；性能各 ≤2 行；合计 ≤15 行 | 硬 |
| 附录 | 单元格 10-80 | 软（WARN） |

## 附录页（基座 slide2/3，模板视觉语言：灰条 + accent1 边框表 + logo 继承）

| 页 | 结构 |
|---|---|
| 附录A 风险预案与有条件立项 | 风险表（风险/影响/应对预案/资源诉求/责任人，行数随 spec 克隆）+ 有条件立项条件（编号列表，左对齐） |
| 附录B 销售预测交叉验证 | 推算链路表（步骤/推算过程/数据来源）+ 对比结论（左对齐） |
