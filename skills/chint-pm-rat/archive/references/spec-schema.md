# 内容规格 JSON Schema v3（spec.json · chint-pm-RAT · PM 范围）

生成器输入：`python3 scripts/fill_one_pager.py spec.json out.pptx`。
完整可运行示例见 [examples/nxm_spec.json](../examples/nxm_spec.json)。

**PM 范围**：本 schema 只含产品经理填写内容。技术可行性、生产可行性、价格成本毛利、
财务可行性由其他部门在 RAT 上续填——spec 里出现这些旧段会被忽略并提示（SCHEMA v3）。

```jsonc
{
  // ── 标题区 ──
  "title_category": "全新开发",           // 改良改进 | 全新开发 | 定制开发
  "title_product": "五金类电动工具ODM导入开发",
  "org_unit": "待项目章程确认",
  "team": {                               // 7 角色必填（可为空串但要给键）
    "负责人": "待定", "产品": "待定", "研发": "待定", "制造": "待定",
    "质量": "待定", "财务": "待定", "供应链": "待定"
  },

  // ── 顶部标签牌（主表灰底单元格）── 平台只允许 昆仑/新锐/诺雅克；跨品类项目填空串并进待确认清单
  "meta": { "需求来源": "中国区", "规划方向": "高性价比", "产品平台": "" },

  // ── 项目计划（写入主表 P1-P4 列）──
  "plan": { "phases": [
    { "name": "P1（项目输入与评估）", "time": "待排期" },
    { "name": "P2（选型与认证验证）", "time": "待排期" },
    { "name": "P3（供应商与品控准备）", "time": "待排期" },
    { "name": "P4（入网与可销售）", "time": "待排期" }
  ]},

  // ── 需求背景 ──
  "research": {                            // intro=首段；items=1、2、…条目（渲染保留编号）
    "intro": "调研时间+对象数量+规模结论…",
    "items": ["现有产品缺口与结论；", "通路限定。"]
  },

  // ── 应用场景及客户痛点 ──
  "scenario_pain": {
    "应用场景": "1-2 句工况描述",
    "客户痛点": [ "每条量化：要求值 vs 现有值（不带编号，渲染为 Ø 列表）" ]
  },

  // ── 快览 ──
  // 竞争对手：只列最大的【一家】（材料一手 → 缺则 research 联网搜市占第一）
  // 目标行业：必须取行业口径枚举之一（10 项，见 industry-enum.md），禁止自造
  "quick_facts": { "竞争对手": "创科实业（TTI）", "目标行业": "建筑地产业务", "销售通路": "…" },

  // ── 产品定义（含性能及质量可靠性，同格渲染）──
  "product_definition": {
    "外观": "…", "材质": "…", "认证": "…",
    "性能参数": [ "逐条回应痛点（渲染为 ➢ 列表，不带编号）" ]
  },

  // ── 附录A：风险预案（PM 拉通内容，有风险必给，四要素齐全）──
  "risks": [{ "风险": "…", "影响": "…", "预案": "…（含量化措施）", "资源诉求": "…", "责任人": "…" }],
  "conditional_approval": ["有条件立项条件 1", "…"],

  // ── 附录B：销售预测交叉验证（有预测必给）──
  "cross_validation": {
    "steps": [{ "步骤": "行业总出货量", "推算": "…", "数据来源": "…" }],
    "对比结论": "结论段（左对齐渲染）"
  }
}
```

## 生成与校验

```bash
python3 scripts/fill_one_pager.py spec.json out.pptx     # 预算预检内建，超限拒生成
python3 scripts/validate_one_pager.py out.pptx --spec spec.json   # PASS 才可交付
bash scripts/render_check.sh out.pptx                    # 150dpi 渲染 + 敏感区裁切
```

校验器含**模板残留检查**（模板原文必须被 spec 全量覆盖或清空）与**字体基线白名单**
（基座字体集之外的新字体=漂移，FAIL；模板原生的微软雅黑/等线允许继承）。
