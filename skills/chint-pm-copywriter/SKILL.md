# B2B Industrial PM Copywriting & Executive Reporting Engine (`chint-pm-copywriter`)

A universal copywriting standard, syntax engine, and quality gate for **B2B Industrial Product Managers (PM)**. Designed for enterprise manufacturing, electrical apparatus, energy systems, and industrial hardware domains to generate plain, pragmatic, highly quantified, and constructive executive copy.

---

## 1. Core Principles: The 4 Invariable Laws (四大铁律)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 1. 极简量化三要素   │ [绝对量增减] + [相对幅度/大盘差] + [关键归因/主体]          │
│ 2. 三段式建设性陈述 │ [基本面/需求基准] + [具体瓶颈/落差事实] + [对应举措/解法]   │
│ 3. 零浮夸战役暗喻   │ 坚决剔除“同室操戈/防线击穿/断档丢高地/深埋反噬”等黑话      │
│ 4. 工业术语精准度   │ 严格区分 “%”、“百分点/点”、“大点/小点”、出厂价与终端到手价 │
└──────────────────────────────────────────────────────────────────────────┘
```

### Law 1: 极简量化三要素 (Metric Triad Rule)
不论何种载体，所有业务洞察必须在一句话内完整交代三要素，彻底禁止无数据支撑的模糊形容词（如“大幅”、“显著”、“明显”）：
* **绝对量**：真实金额/数量（如：`增1.8亿`、`缩水2874万`、`数量增4.8万台`）
* **相对量/大盘差**：增减幅度或对标落差（如：`落后大盘20个点`、`降幅>65%`、`占比升至33.8%`）
* **关键归因/主体**：驱动因素或客户群体（如：`因华为汇川订单缩水`、`盘厂端价差倒挂致重点盘厂流失`）

### Law 2: 负向问题三段式建设性陈述 (Three-Beat Constructive Framing)
面对业绩下滑、客户流失、技术断档、质量波动等负向业务事实时，拒绝单纯情绪化唱衰，必须遵循三段式闭环：
```
【阶段1: 基本面/场景需求满足情况】 ──► 【阶段2: 具体瓶颈/量化落差事实】 ──► 【阶段3: 对应举措/业务解法】
```
> **范例**：`产品满足行业通用场景需求，但受风电1140V高压缺位与送样质量波动影响落后竞品，亟需通过下一代平台化降本与高压技术攻坚重构竞争力。`

### Law 3: 零浮夸黑话与战役暗喻 (Zero Combat Melodrama)
一票否决任何文学化、军事化、生物化或戏剧化的夸张词汇（如：同室操戈、自相残杀、防线击穿、阵地沦陷、断档丢高地、深埋反噬、单核暴雷）。坚守工业制造企业的务实、中立、数据化语态。

### Law 4: 工业与商业术语严谨性 (Industrial Terminology Precision)
* 严格区分 **百分比（%）**（相对变化率）与 **百分点（点/pct）**（两个百分数的差值）；
* 在分销与渠道语境中，准确使用 **大点（面价的1%）** 与 **小点（实际折扣差）**、**下浮率**、**面价指数**、**出厂价**、**盘厂/终端到手价**；
* 在质量与研发语境中，准确使用 **送样一次通过率**、**批次一致性**、**分断能力（Icu/Ics/Icw）**、**额定电压（Ue）**。

## 2. Universal Templates by Deliverable (四大载体标准语法模版)

### 载体 A：向上汇报与经营分析 PPT (Executive Presentation)

#### 1. 主标题模版 (Slide Header)
```
[章节编号] - [主语/产品线] [周期/板块] [性质]：[核心主干事实]，[核心归因/对策]
```
* **业务复盘型**：`1.1 - 正泰ACB 22-25年业务复盘：新能源头部破局驱动份额提升，量额双增`
* **业绩掉队型**：`1.2 - 26H1正泰ACB业绩掉队：落后大盘20个点，渠道与新能源双线下行`
* **问题诊断型**：`1.3 - 正泰ACB产品渠道业务核心问题点：产品价格灵活性不足`
* **应对策略型**：`1.4 – 正泰ACB渠道业务产品应对策略：重启青峰，通过“昆仑+青峰”产品组合拉动销售`
* **多维综合型**：`1.5 - 正泰ACB行业业务复盘：产品满足行业业务需求，存在产品价格竞争力及头部大客户送样质量一致性问题，商务端存在业务拓展问题`

#### 2. 副标题与核心图表洞察 (Insights & Bullets)
```
• [业务主题关键词]：[核心指标量化增减]，[业务占比/大盘变化及点数]，[支撑客户/细分原因]
```
* **量额增长**：`•量额双增：四年收入增1.8亿、数量增4.8万台，行业业务占比提升至33.82% （提升约21点）`
* **份额突破**：`•份额提升：市占率提升1.1%，增速位居国内第二，华为汇川贡献近1亿（占增量54%）`
* **渠道冲击**：`•渠道遭竞品价格冲击：盘厂端价差差异8-16%致渠道减少约2247万，部分重点盘厂业务流失超六成`
* **行业波动**：`•行业客户业绩波动：行业业务下降近三成，其中头部客户华为汇川订单缩水2874万（降幅>65%）`
* **竞品打击**：`德力西组合产品精准打击: 德力西一级经销商价格仅差0.6个大点，但盘厂端德力西通过“领航者+6系列” 的产品组合，整体价格比正泰2-4个大点，约8-16个小点；`

### 载体 B：业务复盘与决策简报 (QBR & Executive Memos)

#### 1. 经营速报 3 句话标准模版 (3-Bullet Executive Memo)
```
1. 【大盘与业绩总览】：[周期]营收[X]亿元（同比[±Y]%），对比大盘增速[±Z]%，核心受[板块A/客户B]波动拉动/拖累。
2. 【结构分化与归因】：[优势板块]增长[A]%贡献增量[B]万；[承压板块]下滑[C]%，主因[渠道价差X点/大客户订单缩水Y万]。
3. 【关键举措与闭环】：通过[策略举措A（如组合定价/高压规格补齐）]，预计[周期]实现增量[M]万，拉动毛利增[N]万（综合毛利稳定在[K]%）。
```

## 4. Pre-Flight Quality Gate Checklist (出稿前 5 项终审门禁)

在输出任何 B2B 工业品 PM 汇报文案、PPT 标题、PRD 或经营速报前，必须逐项通过以下门禁：

```
[ ] 1. 结构规范：主标题是否包含标准章节号、业务板块与核心主旨前缀？
[ ] 2. 黑话一票否决：是否已彻底清除“同室操戈、防线击穿、丢高地、失血、反噬、雪崩”等词汇？
[ ] 3. 三要素量化：每条核心洞察是否均包含【绝对量增减】+【相对幅度/大盘差】+【关键归因】？
[ ] 4. 建设性定调：负向问题是否遵循“先说明需求基准，再陈述量化差距，最后给出举措”的三段式？
[ ] 5. 术语无歧义：是否严格区分了百分比（%）、百分点（点/pct）与渠道大点/小点？
```
