# 法证级数据审查清单

## 一、溯源矩阵模板
| 指标 | 数值 | 单位 | 口径 | 来源文件 | 页码 | 状态 |
|------|------|------|------|----------|------|------|
| ACB 市场容量(2025) | … | 亿元 | ACB 专属 | [1] 格物致胜白皮书 | p.9 | ✅ / ⚠️ |

每个对外数字都要能在矩阵中找到对应行。

## 二、优先级判定
- **P0（致命）**：类别混淆（如把隔离开关计入 ACB）、口径张冠李戴导致结论反转。
- **P1（严重）**：重复计数、装机 / 销量口径矛盾、同指标跨源偏差 >10% 且未解释。
- **P2（优化）**：小数四舍五入、图表样式不统一、表述口径不一致。

## 三、交叉源顺序
`Excel（自有数据）→ PDF 白皮书（格物致胜 / 芯上科）→ 行业报告 → 竞品公开资料`。
每跳都回写溯源矩阵的「状态」列；出现分歧立即挂起并标注，不擅自择一。

## 四、交付前自检
- [ ] 每个对外数字都有 `[文件, p.页码]` 引用。
- [ ] 无 OCR 行号引用（`[1, L141-L160]` ❌）。
- [ ] 容量均带口径标注（全口径 / ACB 专属、装机 / 销量）。
- [ ] P0 / P1 问题已显式列出并给出修正前 / 后。
- [ ] 不确定的事实标「待确认」或「建议向数据源方核实」。
