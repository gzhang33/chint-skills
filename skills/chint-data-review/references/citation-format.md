# 引用格式

## 规则
- 单页：`[1, p.9]`
- 跨页：`[1, pp.16-17]`
- 多源：`[1, p.9][2, p.23]`
- **禁止** OCR 行号：`[1, L141-L160]` ❌

## 示例
正确：专业市场增速 21.1% vs 通用市场 2.1%（十倍增速差）[1, p.9]。
错误：…[1, L141-L160]。

## 页码来源
- PDF 白皮书：物理页码（非 PDF 内部序号；如封面不编页需按正文折算）。
- 飞书文档 / 网页：章节锚点 + 截取说明（如 `飞书《策略报告》§3.2`）。
- 竞品资料：官方手册章节号或页码。

## 不确定性标注
- 正泰内部数据不确定时标「待内部确认」。
- 第三方数据不敢担保时标「待确认」或「建议向数据源方核实」。
